# Builder's Balloon

Tethered creative-style flight for survival building, with colourful wooden and metal anchors and matching decorative rope bollards.

Place a Balloon Tether, double-tap Jump and build inside its cubic boundary. Wood reaches 16 blocks from the anchor centre along each axis by default; metal reaches 32. Right-click an inactive tether with an empty main hand to reactivate it or switch to it while in range. Assign **Pop Balloon** in Controls to release.

All four blocks have 16 dye colours, floor/wall/ceiling placement and waterlogging. Decorative bollards grant no flight; click them with a lead or supported rope to toggle cosmetic wraps without consuming the item.

Create is optional: its wrench picks up every variant with sneak-right-click, and Industrial Iron adds alternative metal recipes. Supplementaries, Farmer's Delight and Quark ropes are supported. Sable support covers stationary and moving sublevels. Metal blocks remain available without Create.

## Install

Use Minecraft Java **1.21.1**, Java **21** and NeoForge **21.1.252**, the tested launch baseline. Later NeoForge 21.1 releases are allowed by metadata but are not claimed as tested. Put the same main mod JAR in client/server `mods` folders; do not install the sources JAR.

## Beta status

The initial release is a beta. Development gameplay and compatibility checks were accepted, and packaged server automation passed. Real multiplayer gameplay testing is deferred. The tested A Good Place placement-animation pack can cause incorrect visuals; see the workaround below.
